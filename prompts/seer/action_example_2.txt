## Example A: Keep a same-question version when there is no substantive change

Constructed version-comparison examples based on supplied SEER case 723, with a non-applicable comparison memory based on case 370. Previous versions and database IDs illustrate decisions and are not claimed as observed database states. Each example has its own output.

### Input

Current question (condensed from case 723): Given an 85-year-old woman's SEER record with Radioactive implants (includes brachytherapy) (1988+), nodes positive 0 and examined 1, ER/PR Positive, HER2 Negative, raw CS tumor size 14, Chemotherapy recode No/Unknown, Vital status Dead, and COD to site recode Alzheimers (ICD-9 and 10 only), choose one radiation/surgery-sequence category.
Reference answer: Radiation after surgery.

The record lists Vital status Dead and COD to site recode Alzheimers (ICD-9 and 10 only); death does not establish a no-treatment answer. The modality name alone does not establish intraoperative or postoperative delivery for other cases.

Applicable Conditions:
