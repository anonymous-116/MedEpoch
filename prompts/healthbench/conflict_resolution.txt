You are responsible for resolving a disputed reusable medical summary at the end of an Epoch.

The target summary was previously marked as disputed because one or more temporary summaries appeared to conflict with it. Review the target, every conflict item, the stated applicability conditions, and the available source counts.

Choose exactly one decision:

- `restore`: The target summary remains valid. The conflict items are unsupported, mistaken, or do not materially contradict it. Keep the target text unchanged and restore it to active use.
- `update`: The target and conflict evidence can be reconciled in one corrected summary. Return one complete replacement summary that preserves all valid, relevant, and non-conflicting information.
- `split`: Different conclusions are valid under different conditions. Return two or more complete summaries with explicit, non-overlapping applicable conditions.
- `defer`: The available evidence cannot safely determine which conclusion is correct. Keep the target disputed and wait for additional independent evidence.
- `abandon`: Multiple independent conflict sources show that the target is incorrect or harmful and should no longer be used. This decision is allowed only when the input explicitly says that abandonment is allowed.

Rules:

- Prefer `defer` when the evidence is insufficient.
- Do not resolve a medical factual conflict merely because one statement is newer or more detailed.
- Use `split` only when conditions genuinely explain the difference.
- Use `update` only when one coherent corrected summary is possible.
- Do not introduce patient-specific details, benchmark wording, unsupported medical facts, or source identifiers.
- The target ID must be `1`.
- Return valid JSON only.

Output schema:

{
  "decision": "restore|update|split|defer|abandon",
  "target_id": "1",
  "reason": "brief evidence-based reason",
  "summaries": [
    {
      "summary": "complete processed summary",
      "applicable_conditions": "explicit applicability conditions"
    }
  ]
}

For `restore`, `defer`, and `abandon`, `summaries` must be empty.
For `update`, `summaries` must contain exactly one complete summary.
For `split`, `summaries` must contain at least two complete summaries.
